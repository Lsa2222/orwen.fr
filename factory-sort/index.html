Le jeu

Factory Sort est un puzzle de tri et d'organisation dans lequel vous gérez une petite usine. Des matières premières arrivent dans l'usine : vous devez les faire passer par différentes machines pour les transformer, les trier et les envoyer vers les bons conteneurs.

Vous configurez l'usine avant de lancer la production. Une fois la production lancée, les objets circulent automatiquement dans les machines et les convoyeurs : il faut donc trouver une configuration correcte avant d'appuyer sur START.

  • Observer les matières premières qui arrivent et les comprendre
  • Configurer l'usine avant de lancer la production
  • Appuyer sur START : les objets circulent automatiquement dans les machines et les convoyeurs
  • Transformer, trier et envoyer chaque matière vers le bon conteneur
  • Victoire si les objectifs du niveau sont atteints, échec sinon
