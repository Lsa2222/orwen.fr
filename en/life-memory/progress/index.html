Life Memory

Life Memory: progress

about 50%

In development

A rough percentage, deliberately cautious. As of October 9, 2026.

The app can be used from start to finish: map, memories with photos, timeline, statistics, search and backup. The latest changes, in September 2026, are about how photos are presented.

This project is on hold for now.

Latest changes

  • Memory page: photos always shown the right way up, with an optional random order (September 2026).
  • Up to three themes per memory, for example Family and Travel (September 2026).
  • Memory album: real pages laid out with several photos, and an animated slideshow (September 2026).
  • Photo carousel, and a choice between all maps or the main map only for the timeline and statistics (September 2026).
  • Several maps possible, and sharing a memory with someone close (September 2026).
  • First version: map, adding a memory with a place, a date and photos, timeline, statistics, search and backup (September 2026).

In progress

  • Finishing touches on how a memory's photos are presented: album, slideshow, order and orientation of photos.

Coming next

  • Idea planned for later: an animation replaying a life on the map, year after year.
  • Idea planned for later: a review of the year, with its places, photos and figures.
  • Idea planned for later: albums put together automatically, for example by country or by season.
  • Idea planned for later: a map where the most lived-in areas stand out more.
