Escaping Monsters

Escaping Monsters: progress

about 65%

Final polish

A rough percentage, deliberately cautious. As of October 9, 2026.

The game plays from start to finish: 15 levels across 3 worlds, 3 bosses to escape, 3 heroes, original music and sound effects. The Android version is written, but it has not yet been checked on a real phone.

This project is on hold for now.

Latest changes

  • Settings screen rearranged: everything fits on a phone without scrolling (September 2026).
  • Privacy policy written and final checklist drawn up (September 2026).
  • Android version written: ads, purchases, cloud save, icon (September 2026).
  • Fairer boss chases: a boss only attacks once it is visible on screen (September 2026).
  • Shop, hero selection, original music and sound effects; all 15 levels checked to be finishable (September 2026).
  • Core gameplay: running, jumping, double jumping, dodging, monsters and bosses (September 2026).

In progress

  • Android version written and a first installable version produced; nothing has been checked on a real phone so far.

Coming next

  • Tests on real phones: touch feel, notched screens, performance on a low-end device, audio volumes.
  • Setting up the game's store listing: texts, screenshots, purchases and cloud save.
  • Putting the privacy policy online.
  • Internal testing phase, then release.
