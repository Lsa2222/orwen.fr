Upix: progress

about 65%

Final polish

A rough percentage, deliberately cautious. As of October 9, 2026.

The app works from start to finish: choosing photos, enhancing them on the device, comparing before and after, saving and sharing. Work now focuses on the quality of the automatic corrections.

This project is on hold for now.

Latest changes

  • Comparison screen: the list of improvements applied to each photo, and its size before and after (October 2026).
  • Automatic corrections that show more, without a filtered look: contrast, colors, deeper pale skies (October 2026).
  • Backlit photos: shadows lifted where needed, and a new correction of color casts (September 2026).
  • AI noise reduction adjusted to the noise measured in each photo (September 2026).
  • First complete version: choosing photos, output resolution, on-device enhancement, comparison, saving and sharing (September 2026).

In progress

  • Tuning the automatic photo processing, for a result that shows but stays natural.
  • Checking each adjustment against a set of fifty test photos.

Coming next

  • Declarations to complete for the store before release: presence of ads and data safety.
  • Release of the first version, with no date announced.
  • Considered for later, nothing promised: face restoration.
